# VEDA Task 30 – Regional Growth Analysis

## Objective
Compare regional growth rates over time.

## Tools
- Microsoft Excel
- SQL / MySQL

## Deliverables
- Dataset
- YoY growth table
- Regional summary
- Excel chart
- SQL queries using window functions
- Five business insights
- Project report

## Key Finding
West is the fastest-growing region with 61.11% total growth from 2019 to 2022. East has the highest sales level, reaching 370,000 in 2022.
